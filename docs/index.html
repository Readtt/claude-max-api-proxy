Install, start, use. Works with anything that speaks OpenAI.

terminal 
# Install globally
npm install -g claude-max-api-proxy

# Start the proxy
claude-max-api &

# Use it with any OpenAI client
curl http://localhost:3456/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-opus-4-6","messages":[{"role":"user","content":"Hello!"}]}'

OpenAI-Compatible

Drop-in replacement. /v1/chat/completions with streaming, tool use, and multi-turn context. Works with Python SDK, Node SDK, curl.

>_

Official CLI

Uses claude --print as a subprocess. No OAuth extraction, no private API scraping. When Anthropic blocked OAuth proxies, we kept working.

$ 

Usage Tracking

GET /v1/usage shows tokens used, requests made, and exactly how much you're saving vs API pricing. Watch the ROI in real-time.

[=]

Streaming

Full SSE streaming support. Real-time token-by-token responses, just like the native OpenAI API.

***

Team Auth

Optional API key authentication for shared deployments. Set API_KEYS env var, require Bearer tokens from clients.
